NicheDesk Analytics

NicheDesk Analytics is a small private tool. It reads the statistics of the owner's own YouTube channels (views, watch time, audience retention, traffic sources, impressions and click-through rate) so the owner can see in one place which videos work and which do not.

It only reads data. It does not upload, edit or delete anything on YouTube, and it is used only by the owner of the channels.
